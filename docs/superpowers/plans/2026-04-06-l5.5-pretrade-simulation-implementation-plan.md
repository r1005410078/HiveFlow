# L5.5 预交易模拟 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 L5.5 预交易模拟：基于 L4 目标权重估算平方根市场冲击（bp）与可成交性，HTTP `POST /api/v1/pretrade/check`、`hf pretrade check` 两跳 CLI，以及 `run_daily` 的 `data.pretrade` 字段；不阻断 pipeline。

**Architecture:** `application/pretrade/pretrade_service.py` 中纯函数式 `run_pretrade_check(as_of, target_weights, bar_store, notional)` 拉取各标的近 20 个交易日 1d K 线，计算 ADV（`mean(close * volume)`）与年化 σ（日收益标准差 × √252，下限 0.01），按设计公式产出 per-symbol 与汇总字段，经 `ok_output` 返回标准 CLI 信封。HTTP 层沿用 `routes_risk.py` 模式（路由只做 DTO + Depends + 调 service）。Rust CLI 与 `hf risk check` 对称：先 `post_portfolio_optimize`，再 `post_pretrade_check`。

**Tech Stack:** Python（FastAPI、numpy/pandas、现有 `application.contracts.cli_output`）、Rust（clap、reqwest、comfy-table）、pytest；无新依赖。

**设计对齐说明：** 规格文档中的路径写为 `POST /v1/pretrade/check`；本仓库 L4/L5 统一为 `/api/v1/...`，本计划采用 **`POST /api/v1/pretrade/check`**（`APIRouter(prefix="/api/v1/pretrade")`），与 `post_portfolio_optimize` / `post_risk_check` 一致。

## 常量与公式（实现时单源引用）

| 常量 | 值 |
|------|-----|
| `ETA` | `0.1` |
| 默认 `notional` | `1_000_000.0`（CNY） |
| 回看交易日数 | `20` |
| `start_date` 缓冲 | 与 L5 类似，取 `as_of - 60 days` 作 `list_bars` 窗口下界 |
| `participation_rate` | `target_notional / ADV`，`target_notional = notional * weight` |
| `tradable` | `participation_rate <= 0.10` |
| `impact_bp` | `ETA * sigma * sqrt(participation_rate) * 10000`（`participation_rate` 为 0 时 impact 为 0） |
| `total_impact_bp` | 各 symbol 的 `impact_bp` 按 `target_weight` 加权平均 |
| `overall_tradable` | 全部 symbol `tradable` |
| 降级 `ADV` | `1_000_000_000.0` |
| 降级 `sigma` | `0.20` |
| 降级 warning | `code: PRETRADE_USING_FALLBACK_ADV`，message 与设计文档一致 |

**`list_bars`：** `timeframe="1d"`，`symbols=list(target_weights.keys())`，`end_date=as_of`，`start_date` 为缓冲日，`limit` 足够大（如 5000）；结果按 symbol 分组、`bar_time` 升序，取不超过 `as_of` 的最后 20 根用于 ADV 与 σ。

- [ ] **Step 2: 编写 5 个失败单测（TDD）**

- [ ] **Step 2: `routes_pretrade.py`**

```python
router = APIRouter(prefix="/api/v1/pretrade", tags=["pretrade"])

@router.post("/check", ...)
def post_pretrade_check(
    req: PretradeCheckRequest,
    service: PretradeService = Depends(get_pretrade_service),
) -> PretradeCheckResponse:
    return PretradeCheckResponse.model_validate(
        service(req.as_of, req.target_weights, req.notional)
    )
```
